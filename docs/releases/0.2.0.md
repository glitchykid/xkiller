Xkiller 0.2.0 refreshes the ETH research workspace with a brutalist interface and persistent light and dark themes.

- Square panels, hard borders and offset shadows, bold typography, numbered navigation, and an acid-lime accent throughout all six sections.
- Light and dark palettes for candlesticks, indicators, learning curves, equity charts, tables, forms, and status messages.
- Theme controls are available on every screen. First launch uses the system preference; an explicit choice persists across desktop restarts and portable extraction locations.
- Accessible theme button states, keyboard focus, compact navigation labels, reduced-motion support, and responsive layouts.
- Updated pinned build tools and automated GitHub release packaging with a SHA-256 checksum.

Download **Xkiller-0.2.0-x64.exe** for Windows x64. The portable application includes Electron and the .NET runtime; no SDK installation is needed. The executable is unsigned.

The application remains a local Bybit ETHUSDT learning and historical simulation lab. It does not send real orders. Existing research data is retained; appearance preferences are saved separately. No trading performance improvement is claimed by this interface release.
